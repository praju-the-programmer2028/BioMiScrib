# BioMiScrib  
### By Prajanya Kannan  

---

## DESCRIPTION

How can a digital tool help people explore their identity?

Many digital tools focus on changing or enhancing appearance. BioMiScrib instead encourages users to understand themselves beyond appearance through an interactive sketching experience that blends self-reflection, science, and creative expression.

At its core, BioMiScrib invites users to view themselves through biological elements:

- Bio = biology  
- Mi = mirror / me  
- Scrib = scribble / doodling  

The project is based on the idea that humans share core biological structures such as hearts, DNA, lungs, and blood, while individuality emerges in how these elements are imagined and represented.

Creating a biological self-portrait is not about altering appearance. It is about exploring identity through shared human structure and personal interpretation.

For me, this project also became a way to reflect on self-esteem and rediscover connection through creativity and biology.

---

## SETTING THE STAGE

BioMiScrib is inspired by a combination of artistic and scientific influences:

- Photobooth culture and instant self-documentation  
- Pop art and everyday visual expression  
- Scientific and medical diagrams  
- Emoji and icon systems  
- p5.js generative drawing capabilities  
- Neon and cyberpunk-inspired aesthetics  

The project was built using p5.js for drawing, getUserMedia for webcam preview, and the MediaRecorder API for recording.

The interface is structured with:
- Tool panel on the left  
- Webcam preview on the top right  
- Drawing canvas in the center  

This layout supports simultaneous self-viewing and creative composition.

---

## HOW IT WORKS

Users select biological icons from the tool panel, including hearts, DNA strands, lungs, bacteria, and blood.

These elements act as visual building blocks for creating a biological self-portrait.

Users then place, draw, and modify elements on the central canvas using interaction tools such as draw, place, and redo.

The webcam preview supports real-time self-viewing during creation, while photos and videos can be saved to document the process.

---

## TYPES OF MIRRORS

- **Literal Mirror:** Webcam shows the user during creation  
- **Visual Mirror:** Biological icons represent human structure  
- **Psychological Mirror:** Creation becomes self-reflection  
- **Social Mirror:** Shared biology fosters empathy  

BioMiScrib focuses on identity through biology and symbolic representation rather than physical realism. Users often create abstract or playful compositions that reflect personal interpretation.

## FINAL THOUGHTS

BioMiScrib was built from the question: “What are you made of?”

The project combines biology, art, and technology to create a tool for self-exploration through visual expression.

Its aesthetic draws from photobooth visuals, pop art, scientific illustration, and icon design systems.

The final version emphasized playful interaction, which encouraged users to create abstract biological portraits during testing and presentations.

This process highlighted how interacting with scientific concepts through art can shift perspective and support reflection on identity.
